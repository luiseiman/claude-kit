## Description

Opus 4.8 released as GA in v2.1.154 (2026-05-27). Defaults to `high` effort with `xhigh` available (still Opus-exclusive — Sonnet/Haiku fall back to `high`). Fast mode (`/fast`) on Opus 4.8 trades **2x standard rate for 2.5x speed** — the cost/speed knob is more aggressive than the 4.7 fast-mode tradeoff.

`domain/model-ids.md` lists Opus 4.7 as the tier-top. Need to add a 4.8 row and re-anchor the "most recent" comment that current Opus 4.7 holds.

## Evidence

CHANGELOG v2.1.154: "Opus 4.8 released; defaults to high effort/xhigh". "Fast mode on Opus 4.8 now 2x standard rate for 2.5x speed". v2.1.156 hotfix: "Thinking blocks modified when using Opus 4.8 causing API errors, now fixed" — confirms 4.8 is in active production use.

## Impact on dotforge

- `domain/model-ids.md` — add row for `opus` → `claude-opus-4-8` (1M context, 128K max output). Demote 4.7 to a "previous opus" footnote.
- Update model-routing.md: if any rule pins `claude-opus-4-7` explicitly (vs alias `opus`), confirm intent — aliases now resolve to 4.8.
- `agents/*.md` model frontmatter: agents using alias (`opus`) auto-upgrade. Agents pinned to `claude-opus-4-7` need explicit decision (re-baseline benchmarks or keep pin).
- Fast mode advisory in domain rule: 4.8 fast = aggressive (2x/2.5x), 4.7 fast = milder. Choosing one is now an explicit cost/latency call.
