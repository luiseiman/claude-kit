## Description

Bundle de 6 features de Claude Code v2.1.162 (release 2026-06-03). Detectado en `/forge watch` del 2026-06-17. Predominantemente UX/observability — sin breaking changes. Captured as a bundle para evitar 6 archivos en inbox por features de bajo costo.

## Features

1. **`claude agents --json` includes `waitingFor` field** (medium)
   - Permite ver qué bloquea una bg session (permission prompt, deferred tool, etc.)
   - Impact: `agent-orchestration.md` § Background sessions observability
2. **`--tools "Grep,Glob"` activates native searchers explicitly** (medium)
   - Comportamiento conditional: en native macOS/Linux builds, listing Grep/Glob explícito habilita los `bfs`/`ugrep` embebidos vs el fallback Bash
   - Impact: `cli-flags.md` `--tools` description + cross-ref a `permission-model.md` (que ya documenta que native builds reemplazan Glob/Grep)
3. **`/effort` persistence confirmation** (low)
   - Después de elegir nivel, emite "this will be the default for new sessions"
   - Impact: `model-ids.md` § Effort levels — nota UX
4. **Slash command autocomplete: fill not execute** (low, UX)
   - Tab/Enter ahora llena el prompt en vez de ejecutar inmediatamente
   - Impact: ninguno funcional para dotforge; nota en `cli-flags.md` autocomplete behavior
5. **Remote Control: persistent footer pill** (low, UX)
   - Reemplaza "startup message" como visibility del estado remote
   - Impact: ninguno para dotforge
6. **Windsurf → "Devin Desktop"** (cosmetic)
   - Rename en `/ide`, `/terminal-setup`, `/scroll-speed` menus
   - Impact: ninguno

## Impact on dotforge

- `domain/agent-orchestration.md` — add `waitingFor` field to background sessions section
- `domain/cli-flags.md` — extend `--tools` description with native-search activation pattern; brief autocomplete behavior change note
- `domain/model-ids.md` — `/effort` persistence note in effort section
